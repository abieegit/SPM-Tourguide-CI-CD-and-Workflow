# TourGuide

Trip booking web application with destination browsing, gallery, booking, contact, and a full admin panel (CRUD on all content).

## Tech Stack
MongoDB, Express.js, React.js, Node.js (MERN)

## Team
- Abdullah (Project Lead / Full-Stack Developer)
- Ahmed Zia (Frontend Developer / Documentation)

## Branching Strategy
- `main` — stable, production-ready code
- `dev` — active development integration branch
- `feature-*` — individual feature branches, merged into `dev` via PR
